# Documentation Sources

- Use the configured Context7 MCP for version-sensitive library/framework APIs,
  dependency upgrades, setup, configuration, and code-generation questions.
- Send only a focused library/version question. Never send secrets, customer
  data, proprietary source, or an entire user prompt to a documentation service.
- Context7 does not override repository-local rules, architecture, lockfiles, or
  existing implementation decisions.
- If Context7 is unavailable, report that limitation and consult official
  vendor documentation. Never invent an API or block unrelated work.
- Authentication is user-owned. Never request that a user paste an API key into
  chat and never commit an MCP credential.
